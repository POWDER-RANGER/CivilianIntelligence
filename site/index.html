CIVWATCH web app · source repository

Who is watching your town, who paid for it, and how to challenge it.

This repository is the CIVWATCH web app: a map of documented surveillance cameras, the contracts and filings behind them, and a toolkit that drafts the records request. Every record links to its source and shows when it was last checked.

Open the web app Read the source

Runs on free hosting. If the app has been idle, the first page can take up to a minute to load.

What the app does

Each part of the app answers one question and cites the public system it reads from.

PartAnswersReads from
MapWhere are documented license-plate readers, and which way do they face?OpenStreetMap ALPR tags via DeFlock vector tiles
Place lookupWhich city, county and districts cover this address, and what is nearby?U.S. Census geocoder and geographies
MoneyWhich federal awards and company filings touch this subject?USAspending, SEC EDGAR
Federal actionsWhat rules and notices did agencies publish today?Federal Register API
Records toolkitHow do I ask for the contract, policy or audit log?FOIA, Privacy Act and state public-records statutes
Cell MonitorWhat did my own phone observe about the cell network around it?A local app on your computer; separate repository

How every record is sourced

A mapped camera is a documented location, not proof of an operating camera. The app says what it knows, where it came from and when it was checked.

  1. Source on every line

    Each record carries its source link, the date it was retrieved and the date it was last verified.

  2. Verification is shown, not implied

    Records are marked Verified (primary document), Reported (secondary source) or Unverified (tip).

  3. Examples are labeled

    Sample and fixture data use SAMPLE- IDs and a banner. Nothing invented is shown as live.

  4. Corrections are public

    Anyone can report an error; fixes are logged.

Run it yourself

Node 22. Postgres (Neon) is optional; without it the record index runs read-only. API keys for Congress.gov and api.data.gov unlock those feeds.

git clone https://github.com/POWDER-RANGER/CivilianIntelligence.git
cd CivilianIntelligence
npm ci
npm run dev

CIVWATCH documents publicly visible infrastructure and public records about government surveillance technology. Locations come from public records, open data (OpenStreetMap) and volunteer reports; each shows its source and verification status. We do not access camera feeds, intercept communications or track individuals. Vendor names identify vendors only; CIVWATCH is not affiliated with any vendor or government agency.
